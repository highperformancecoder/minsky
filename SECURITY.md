# Security Policy

## Supported Versions

Only the latest release version and head of the master branch is supported. Please also report any security issues on develop branch (beta releases), to ensure a timely fix  into the release version.

## Reporting a Vulnerability

If the vulnerability doesn't need any confidential information reported, please report the vulnerability using [Github issues](https://github.com/highperformancecoder/minsky/issues). If the report needs to be treated confidentially, then please fill out the ["Contact Us" form](https://marketing.ravelation.net/support)
